PromediaApp - Calculadora de Notas 

Proceso Guiado en 4 Pasos:avegación paso a paso para evitar errores al configurar asignaturas.
Validación Estricta: Revisa que el total de porcentajes sume exactamente 100%.
Análisis Predictivo: Recomienda las notas mínimas que debes obtener en las evaluaciones restantes para alcanzar tu meta.
Simulador en Tiempo Real: Experimenta con un slider para evaluar cómo afectaría cualquier nota hipotética a tu promedio final.
Historial Local: Guarda tus materias automáticamente usando el almacenamiento local del navegador (`localStorage`).
